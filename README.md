# UMLmaid

UMLet과 Mermaid의 장점을 합친 UML 다이어그램 도구입니다. 소프트웨어공학 팀 프로젝트로 만듭니다.

- **코드로 그린다:** 익숙한 Mermaid 문법으로 객체와 관계를 정의하면 1초 안에 자동 배치된다.
- **마우스로 배치한다:** 노드를 끌어서 옮기면 그 위치가 고정되고, 코드에 노드를 추가해도 고정된 위치는 유지된다.
- **논문용으로 내보낸다:** 화면에 보이는 그대로 PNG·JPEG로 내보낸다.

지원 범위: 클래스 다이어그램, 시퀀스 다이어그램

## 기술 스택

TypeScript · React · Vite · elkjs(자동 배치) · Vitest
